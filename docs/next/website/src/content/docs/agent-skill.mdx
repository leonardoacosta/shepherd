Shepherd ships a reusable agent skill file at [`SKILL.md`](https://github.com/leonardoacosta/shepherd/blob/master/SKILL.md).

Install that file into any coding agent that supports reusable skills or custom instructions. The skill teaches the agent how to control Shepherd from inside a Shepherd pane.

Shepherd also serves a separate guide at [`shepherd.dev/agent-guide.md`](https://shepherd.dev/agent-guide.md) for a different job: an agent helping a human learn, set up, or troubleshoot Shepherd. The skill is for an agent operating Shepherd; the guide is for an agent teaching a human.

## What the skill does

The skill tells an agent to use the `shepherd` CLI when `SHEPHERD_ENV=1` is set. That means the agent is running inside a Shepherd-managed pane and can safely talk to the local Shepherd socket.

With the skill installed, an agent can:

- inspect workspaces, tabs, panes, and neighboring agents
- split panes and run commands without stealing focus
- read pane output and recent logs
- wait for servers, tests, or another agent to finish
- start helper agents in sibling panes

The skill is not a separate app or service. It is a markdown instruction file for agents.

## Install it

Install the skill with `npx skills`:

```bash
npx skills add leonardoacosta/shepherd --skill shepherd -g
```

The `-g` flag installs it globally for supported agents. Omit `-g` to install it into the current project.

Use the repository copy as the manual fallback and source of truth:

```text
https://github.com/leonardoacosta/shepherd/blob/master/SKILL.md
```

For agents with a skill system, install that file as a skill named `shepherd`. For agents without a skill system, paste the file into the agent's project or user instructions.

After installation, start the agent inside Shepherd:

```bash
shepherd
claude
```

Or use any other coding agent in a Shepherd pane. The important part is that the agent process runs inside Shepherd, so `SHEPHERD_ENV=1` is available.

## Safety rule

The skill starts with one guardrail: if `SHEPHERD_ENV=1` is not set, the agent should stop and say it is not running inside a Shepherd-managed pane.

This prevents an agent outside Shepherd from trying to control a session it does not own.
